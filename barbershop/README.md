# Демо-сайт барбершопа «OAK & STEEL»

Готовый одностраничный сайт для показа клиентам. Название, цены и иллюстрации вымышлены.
Сайт состоит из обычных файлов (HTML, CSS, JavaScript): ничего не нужно собирать или устанавливать,
поэтому его можно бесплатно разместить на Cloudflare Pages.

## Что лежит в папке

| Файл | Зачем нужен |
|---|---|
| `index.html` | Сам сайт: тексты, услуги, цены, галерея |
| `js/config.js` | **Настройки**: WhatsApp, Telegram, телефон, адрес, часы работы |
| `css/style.css` | Оформление (цвета — в самом начале файла) |
| `js/main.js` | Меню, форма записи, кнопки мессенджеров. Трогать не нужно |
| `images/` | Иллюстрации галереи и значок сайта |
| `404.html` | Страница «не найдено» |

## Часть 1. Как указать свои контакты (с телефона)

1. Откройте в браузере телефона свой репозиторий на github.com и войдите в аккаунт.
2. Откройте репозиторий `barbershop-demo` и перейдите: папка `barbershop` → `js` → файл `config.js`.
3. Нажмите на значок карандаша ✏️ (Edit). Если его не видно — в меню браузера включите «Версия для ПК».
4. Впишите данные **между кавычками**:
   - `whatsapp: "79990000000"` — номер только цифрами, с кодом страны, без `+` и пробелов;
   - `telegram: "имя_пользователя"` — без `@`;
   - `phone`, `address`, `hours` — как они должны выглядеть на сайте.
5. Нажмите зелёную кнопку **Commit changes…** → ещё раз **Commit changes**.

Для показа клиентам можно указать **свой** Telegram или WhatsApp — тогда заявки с демо-сайта будут приходить вам.
Пока поле пустое, кнопка не ломается: посетитель видит подсказку «Контакт пока не подключён».

> Важно: в Telegram нельзя заранее подставить текст в личный чат. Поэтому сайт копирует текст заявки,
> а посетителю остаётся вставить его в чат. В WhatsApp текст подставляется сам.

## Часть 2. Публикация через Cloudflare Pages (бесплатно)

1. Откройте **dash.cloudflare.com** и зарегистрируйтесь (нужна только почта).
2. В меню слева выберите **Workers & Pages** (на телефоне меню открывается кнопкой ☰).
3. Нажмите **Create** (Создать) → вкладка **Pages** → **Connect to Git** (Подключить Git).
   Если Cloudflare предлагает создать Worker — найдите ссылку про **Pages**: нужен именно Pages.
4. Выберите **GitHub** и разрешите Cloudflare доступ. Можно дать доступ только к этому репозиторию.
5. Выберите репозиторий и нажмите **Begin setup**.
6. Заполните настройки:
   - **Project name** — латиницей, например `oak-steel-demo`. Из него получится адрес `oak-steel-demo.pages.dev`;
   - **Production branch** — `main`;
   - **Framework preset** — `None`;
   - **Build command** — оставить **пустым**;
   - **Build output directory** — `barbershop`.
7. Нажмите **Save and Deploy** и дождитесь сообщения об успешной публикации (обычно меньше минуты).
8. Откройте выданный адрес `….pages.dev` и проверьте сайт: меню, кнопки записи, галерею.

Названия кнопок в Cloudflare иногда меняются — ищите близкие по смыслу.
Сайт считается опубликованным только после того, как адрес `….pages.dev` открывается у вас в браузере.

**Дальше всё автоматически:** любое изменение файла на GitHub (например, новая цена) через минуту появляется на сайте.

## Часть 3. Как адаптировать сайт под реального клиента

- **Название и тексты** — в `index.html` (кнопка ✏️, поиск по странице в браузере поможет найти нужное место).
- **Цены** — в `index.html`, строки вида `от 1 800 ₽`. Список услуг в форме записи обновится сам.
- **Фото работ** — загрузите фото в папку `images` (**Add file → Upload files**), затем в `index.html`
  замените, например, `images/work-fade.svg` на `images/имя-вашего-фото.jpg` и поправьте подпись и `alt`.
  Сжимайте фото до 200–400 КБ (например, через сайт squoosh.app), чтобы сайт быстро открывался.
- **Адрес и карта** — в `js/config.js` (поля `address` и `mapUrl`).
- **Пометка «демонстрационный сайт»** — удалите её в самом низу `index.html` и в теге `<title>`,
  когда сайт станет настоящим.
- **Свой домен** клиента подключается в Cloudflare: проект → **Custom domains**.

## Что можно предлагать в ежемесячном обслуживании

Обновление цен и услуг, замена фото, проверка, что кнопки записи работают, продление домена,
сезонные акции на главном экране.
