# barbershop-demo

Демонстрационный сайт барбершопа. Все файлы сайта лежат в папке [`barbershop`](barbershop/).

Инструкция — как указать свои контакты и опубликовать сайт через Cloudflare Pages с телефона:
[barbershop/README.md](barbershop/README.md).

При публикации в Cloudflare Pages: **Build command** — пусто, **Build output directory** — `barbershop`.

---

## ElFoxo — демоверсия редизайна

В папке [`elfoxo`](elfoxo/) лежит отдельный демо-сайт интернет-магазина детских головных уборов ElFoxo
(товары, цены и иллюстрации условные). Запуск и публикация описаны в [elfoxo/README.md](elfoxo/README.md).
Для отдельного проекта Cloudflare Pages: **Build output directory** — `elfoxo`.
