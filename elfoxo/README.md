# ElFoxo — демоверсия редизайна

Демонстрационный интернет-магазин детских головных уборов и аксессуаров в стиле
«скандинавский минимализм + премиальный e-commerce». Статичный сайт: HTML, CSS и JavaScript
без сборки и сторонних библиотек.

> **Всё содержимое демонстрационное.** Товары, артикулы (`DEMO-…`), цены, тексты о бренде
> и иллюстрации условные — это не реальный ассортимент и не условия ElFoxo.
> Контакты и условия доставки/оплаты не заполнены. Сайт закрыт от индексации (`noindex`, `robots.txt`).

## Запуск на компьютере

```bash
cd elfoxo
python3 -m http.server 8080
```

Откройте в браузере http://localhost:8080. Подойдёт любой статический сервер (например, `npx serve elfoxo`).

## Что есть на сайте

- Шапка с меню, поиском и корзиной; мобильное меню.
- Главный экран, категории, каталог, новая коллекция, блок о бренде, преимущества и условия заказа, подвал.
- Каталог: фильтр по категориям, поиск, сортировка, переключение цвета прямо в карточке.
- Быстрый просмотр товара (цвет, размер, комплектность, количество) по ссылке вида `#product=fox-beanie`.
- Таблица размеров.
- Корзина хранится в браузере (localStorage). «Оформить заказ» показывает демо-окно:
  оплата не подключена, персональные данные не собираются.
- Анимации учитывают настройку `prefers-reduced-motion`.

## Файлы

| Файл | Назначение |
|---|---|
| `index.html` | Разметка страницы |
| `css/style.css` | Оформление; цвета, отступы и скругления — в начале файла |
| `js/catalog.js` | **Каталог**: категории, цвета и товары (демо-данные) |
| `js/config.js` | **Контакты и условия** заказа (сейчас пустые) |
| `js/main.js` | Логика: фильтры, просмотр товара, корзина, меню |
| `images/products/` | Иллюстрации товаров: `<id>-<цвет>-480.webp` и `-960.webp` |
| `images/scenes/` | Главный экран, категории, коллекция, о бренде |
| `404.html`, `robots.txt`, `_headers` | Страница ошибки и настройки для Cloudflare Pages |

## Как заменить на настоящие данные

1. **Товары** — отредактируйте `js/catalog.js`: названия, артикулы, цены, размеры, цвета, комплектность.
2. **Фото** — положите фото в `images/products/` по шаблону `<id товара>-<ключ цвета>-480.webp` и `-960.webp`
   (пропорции 4:5). Затем уберите подписи «Демо-иллюстрация» в `index.html` и `js/main.js`.
3. **Контакты и условия** — заполните `js/config.js`.
4. **Пометки «демоверсия»** — уберите полосу `demo-bar` и тексты-заглушки в `index.html`,
   а также `noindex` в `index.html`, `robots.txt` и `_headers`, когда сайт станет настоящим.

## Иллюстрации

Внешние фотобанки из среды разработки были недоступны, поэтому иллюстрации нарисованы программно:
это векторные сцены с фактурой вязки, переведённые в WebP. Исходник — `tools/elfoxo-images/`
в корне репозитория. Пересобрать после правки `js/catalog.js`:

```bash
node tools/elfoxo-images/generate.mjs
```

(нужны Node.js, Playwright с Chromium и ImageMagick с поддержкой WebP).
